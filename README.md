# Bazaar-Guru

A comprehensive business accounting and management application inspired by Vyapar Business App.

## Features
- Complete Indian GST Billing (Tax Invoices, Bills of Supply, Credit/Debit Notes)
- Double-Entry General Ledger & Chart of Accounts
- Customer & Supplier Party Ledgers with running balances
- Purchase Bills & Expense Tracking
- Multi-theme PDF Generation & 80mm Thermal Receipt printing
- Spreadsheet Exports (.xlsx, .csv) & Financial Reports
- Offline-First Architecture powered by IndexedDB with Supabase synchronization

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```
2. Configure `.env` with your Supabase credentials (see `.env.example`).
3. Run the development server:
   ```bash
   npm run dev
   ```
4. Build for production:
   ```bash
   npm run build
   ```
